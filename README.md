E-Commerce Sales Analysis 📊
Project Overview

This project analyzes e-commerce sales data using SQL and Python to uncover business insights, customer behavior, product performance, and sales trends.

The analysis includes data cleaning, exploratory data analysis (EDA), SQL queries, business KPI analysis, data visualization, and customer segmentation using RFM analysis.

🎯 Project Objectives
Analyze overall sales performance.
Identify monthly revenue trends.
Find the best-performing product categories.
Analyze revenue across different regions.
Identify top-performing products.
Identify high-value customers.
Analyze customer segments.
Perform RFM customer segmentation.

🧹 Data Cleaning

The following steps were performed:

Checked dataset structure and data types.
Checked for missing values.
Converted date columns to datetime format.
Identified duplicate records.
Removed duplicate rows from the orders dataset.
Validated customer IDs, product IDs, and order IDs.

📈 Key Insights
Furniture generated the highest revenue.
Electronics was the second-highest revenue-generating category.
The North region generated the highest revenue.
Consumer was the largest customer segment by revenue.
Wardrobe was the highest revenue-generating product.
Priya Singh was the highest revenue-generating customer.
Revenue showed fluctuations across different months.
Customer segmentation identified Champions, Loyal Customers, Potential Loyalists, Regular Customers, At Risk Customers, and Lost Customers.
👥 Customer Segmentation

RFM analysis was performed using:

Recency – Days since the customer's latest purchase.
Frequency – Number of purchases made.
Monetary – Total revenue generated by the customer.
